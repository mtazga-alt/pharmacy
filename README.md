# 💊 صيدليتي — نظام إدارة صيدلية بالباركود

تطبيق ويب يعمل من الكمبيوتر والجوال ويُرفع على **GitHub Pages**. فكرته أنك **تبني قاعدة بيانات الأدوية بنفسك**: تمسح باركود الدواء، فإن كان مسجلاً تظهر بياناته، وإن لم يكن يفتح التطبيق نموذج إضافته فوراً بالحقول التي يحددها المسئول من الإعدادات.

## المميزات
- **3 أنواع دخول:** مسئول، صيدلي، مواطن (المواطن يدخل بدون حساب).
- **قراءة الباركود بكاميرا الجوال** (EAN-13 و Code128 و QR و DataMatrix)، **وقارئ USB** على الكمبيوتر.
- يقرأ كود **GS1 DataMatrix** الموجود على علب الأدوية، ويستخرج منه **تاريخ الصلاحية تلقائياً**.
- **حقول الدواء قابلة للتعديل** من الإعدادات: إضافة حقل، حذفه، ترتيبه، تحديد نوعه، وجعله إلزامياً أو ظاهراً للمواطن أو في الجدول.
- نقطة بيع وفواتير وطباعة إيصال، وتنبيهات لنفاد الكمية وقرب انتهاء الصلاحية، وتقارير بالأكثر مبيعاً.
- تصدير واستيراد بملفات CSV تفتح في Excel، ونسخ احتياطي كامل.
- يعمل بدون إنترنت، ويمكن **تثبيته على الجوال كتطبيق** (PWA).

## الرفع على GitHub Pages
1. أنشئ مستودعاً جديداً على GitHub (مثلاً `pharmacy`).
2. ارفع **كل محتويات المجلد** كما هي، مع المجلدات الفرعية (`css`, `js`, `lib`, `icons`).
3. من المستودع: **Settings ← Pages ← Source: Deploy from a branch ← main / root ← Save**.
4. بعد دقيقة يصبح الرابط جاهزاً: `https://اسمك.github.io/pharmacy/`

> الكاميرا لا تعمل إلا من رابط آمن **https**، وهذا متوفر تلقائياً في GitHub Pages.

**أول دخول:** اسم المستخدم `admin` وكلمة المرور `admin123`، وسيطلب منك التطبيق تغيير كلمة المرور فوراً.

## قاعدة البيانات
### الوضع المحلي (الافتراضي)
البيانات تُحفظ داخل متصفح كل جهاز (IndexedDB). هذا الوضع مناسب لجهاز واحد في الصيدلية. خذ نسخة احتياطية بشكل دوري من **الإعدادات ← النسخ الاحتياطي**.

### الوضع السحابي المشترك (Firebase، مجاني)
في هذا الوضع يتشارك الكمبيوتر وجوالات الصيادلة والمواطنين نفس البيانات، وتتحدث لحظياً على كل الأجهزة.
1. ادخل https://console.firebase.google.com ← **Add project**.
2. من **Build ← Firestore Database ← Create database**.
3. من إعدادات المشروع ⚙️ ← **Your apps ← Web `</>`** ← انسخ `firebaseConfig`.
4. افتح الملف `js/config.js` وضع الإعدادات مكان `null`، ثم ارفع الملف على GitHub.
5. ستتصل كل الأجهزة تلقائياً. لنقل بياناتك القديمة: صدّر نسخة احتياطية قبل التحويل، ثم استوردها بعده.

**قواعد Firestore المقترحة** (Firestore ← Rules):
```
rules_version = '2';
service cloud.firestore {
  match /databases/{db}/documents {
    match /{document=**} { allow read, write: if true; }
  }
}
```
⚠️ **ملاحظة أمان:** نظام الدخول في هذا التطبيق يعمل داخل المتصفح، وكلمات المرور محفوظة مشفّرة (SHA-256). هذا كافٍ لتنظيم الصلاحيات داخل الصيدلية، لكنه لا يحمي البيانات من شخص تقني يعرف رابط مشروعك على Firebase. إذا كنت تحتاج حماية أقوى، أضف Firebase Authentication وقواعد صلاحيات أدق.

## هيكل الملفات
```
index.html          الصفحة الرئيسية
css/style.css       التصميم
js/app.js           منطق التطبيق
js/config.js        إعداد Firebase (اختياري)
lib/                مكتبة الباركود والأيقونات وخط Cairo (تعمل بدون إنترنت)
icons/              أيقونات التطبيق
manifest.json, sw.js  التثبيت على الجوال والعمل بدون إنترنت
```
